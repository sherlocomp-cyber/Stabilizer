# Stabilizer

Aplikasi Android untuk memantau dan membantu menstabilkan koneksi 5G XL di iQOO 15R dan POCO F5. Tanpa root.

Rencana fitur:
- Monitor sinyal 4G/5G (RSRP, RSRQ, SINR, band)
- Uji kualitas koneksi (ping, jitter, packet loss, kecepatan)
- Penjaga koneksi di latar belakang dan notifikasi saat putus
- Mode Fokus Aplikasi: prioritaskan koneksi untuk satu aplikasi

Catatan: aplikasi biasa tidak bisa menambah kekuatan sinyal atau mengunci band. Detail batas teknis dan roadmap ada di [CATATAN.md](CATATAN.md).

Status proyek dan langkah berikutnya selalu diperbarui di CATATAN.md supaya bisa dilanjutkan dari akun mana pun.
